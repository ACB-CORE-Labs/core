# B2.4 — Lexicon, Composition & Style Extensions

**Zone / stack:** B2.4 (macro layers M1/M3) | **Tier:** B | **Batch:** 2 (ADR-0051–0100)
**Members:** ADR-0065, ADR-0083, ADR-0084, ADR-0085, ADR-0087 | **Card author:** Claude (Tier B audit agent, Sonnet 5)
**`verified_at` SHA:** `cbfc8ccb` (`cbfc8ccbf7fe503ab31abe7aedbb1973ba7d7b4d`)

These five ADRs were scoped as one zone because they all extend the lexicon/composition surface, but they are **not** one sequential arc — verification shows two genuinely coupled pairs and two loosely-related singletons. ADR-0084 (Definitional Layer) and ADR-0085 (Gloss-Aware CAUSE Composer) are a real producer/consumer pair: `chat/pack_grounding.py::gloss_aware_cause_surface` literally calls `chat/pack_resolver.py::resolve_gloss` against the `glosses.jsonl` substrate ADR-0084 created, and ADR-0085's own text names ADR-0084 as the thing it "cannot exist without." ADR-0083 (Transitive Chain Surface) sits one step further back in the same CAUSE-intent dispatch chain in `chat/runtime.py` — the gloss-aware path is tried first, then falls through to the ADR-0083 transitive composer, then to the ADR-0062 composed surface, then to single-chain — so 0083 and 0085 interact functionally at runtime even though neither ADR cross-references the other. ADR-0065 (OOV gradient + relations v2) is architecturally independent of the other four: it operates one layer up the honesty-tier ladder (what surface to show when a lemma is *unknown*, not how to phrase a surface for a lemma that *is* known), and none of the other four ADRs' artifacts appear in its call chain or vice versa. ADR-0087 (Rhetorical Style) is the outlier: it is explicitly *substrate-only, no consumer*, reuses the "pack the operator mounts, not a compose-time motor" pattern and the "ADR-0084→0085 substrate-then-consumer sequencing" as design precedent, but shares no code or data with any other zone member — and, per the brief's hypothesis, its pack loader (`packs/rhetorical_style/loader.py`, 425 lines) is confirmed to be the exact loader Batch 1's `AA-111` flagged as one of the five-plus duplicated pack-loader skeletons (line count matches `AA-111`'s citation verbatim). All five ADRs' claimed code artifacts were found and all 200 of their dedicated tests pass at the verified SHA (`test_oov_surface.py`, `test_partial_surface.py`, `test_oov_pipeline.py`, `test_en_core_relations_v2_pack.py`, `test_transitive_surface.py`, `test_adr_0084_definitional_substrate.py`, `test_adr_0084_integration_closure.py`, `test_adr_0085_gloss_aware_cause.py`, `test_adr_0087_rhetorical_style_substrate.py` — run directly during this audit, 200 passed).
